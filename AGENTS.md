# Brand naming

Always write the user-facing app name as `geet`, all lowercase, including at the beginning of a sentence. This applies to interface copy, menus, accessibility labels, app display metadata, documentation, and brand assets.

Use Newsreader for brand typography. The Listener logo and app icons must stay text-free.

Don't display the app name in the main window header. Keep its search, add, and settings controls; secondary screens may retain their descriptive titles.

Preserve existing Swift type and module names, executable and resource filenames, bundle identifiers, and the application-support folder unless a task specifically requires migrating them. Those are implementation identifiers, not the displayed brand name.
