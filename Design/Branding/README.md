# geet brand

geet uses the Listener portrait as its logo and Newsreader as its brand typeface. Always write the app name as `geet`, all lowercase, including at the start of a sentence.

The logo, app icon, and menu bar icon are text-free. The brand name and headlines are separate typography; don't add them to the symbol or create a permanent text-and-symbol lockup.

## Typography

Use Newsreader Regular, weight 400, for the geet name, brand headlines, and editorial messages. Keep normal letter spacing. Use optical size 72 for large display work; for smaller headings, match the optical size to the text size within the font's 6–72 range.

The main window header has no app-name label. The app uses Newsreader at 24 points for editorial headings and 28 points for the support headline. Buttons, menus, settings labels, playlist rows, captions, and body copy use the native macOS system font.

The Newsreader font and its SIL Open Font License are included in [the asset package](Listener/README.md). No system-wide font installation or network font loading is required.

## Color and artwork

Use ink `#20211C`, ivory `#F4F0E7`, and forest `#355A48` for the core identity. Muted amber `#C19A63` is a supporting artwork color. Preserve the Listener's profile, bob, headphones, and transparent negative space.

The [Listener asset guide](Listener/README.md) covers icon formats, clear space, and reproduction. The [typeface comparison](Typography/README.md) records the font-selection study; Newsreader is the selected family.
